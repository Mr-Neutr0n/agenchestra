# Standartlar ve şablonlar

`orkestra standart goster <ad>` standardı gösterir.

## Standartlar

- `best_in_class`: Best in class standardı (P-030)
- `commit`: Commit mesajı standardı (Conventional Commits)
- `dal`: Dal adı standardı
- `jira_yorum`: Jira Done yorum standardı
- `kabuk_profili`: Kabuk profili (P-043, ADR-0102)
- `kok_neden`: Kök neden önce (P-042, ADR-0101)
- `onleme_merdiveni`: Önleme merdiveni (P-045, ADR-0042, ADR-0111)
- `pr`: Pull request standardı
- `review`: Review standardı

## Belge şablonları

- `bulgu`: {baslik}: bulgu
- `calisma_ozeti`: {baslik}: çalışma özeti ({tarih})
- `jira_onerisi`: {baslik}: Jira güncelleme önerisi (Jira'ya yazılmadı)
- `mevcut_durum`: {baslik}: mevcut durum
- `plan`: {baslik}
- `plan_dogrulamali`: {baslik}: plan
- `plan_sirali`: {baslik}: plan
- `rapor`: {baslik}: rapor
- `sozlesme`: {baslik}: görev sözleşmesi
- `todo`: {baslik}: yapılacaklar
